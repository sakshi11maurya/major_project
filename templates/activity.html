Activity Monitoring Information

  • Login Time: Records the exact timestamp when a user logs in to the system.
  • Logout Time: Records the timestamp when a user logs out. Shows "-" if session is still active.
  • Duration: Shows how long the session lasted. Active sessions update in real-time.
  • IP Address: Tracks the source IP address of the login, useful for security audits.
  • Status: Shows whether the session is currently active or has been completed.

Security & Monitoring Features

🔍 Session Tracking

Monitor all user sessions with precise login and logout timestamps for audit trails.

🌐 IP Monitoring

Track the IP addresses from which users access the system for security compliance.

⏱️ Duration Analysis

Analyze session durations to understand system usage patterns and user behavior.

🔒 Admin Controls

Administrators can view all user activities while users see only their own sessions.
